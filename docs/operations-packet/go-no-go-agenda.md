# Go/No-Go Agenda

## Meeting objective

Decide if the release can enter staged rollout based on governance checks, risk posture, and operational readiness.

## Inputs

- Governance summary report
- Rollout waves validation output
- Change approval record
- Active incident status

## Agenda (30 minutes)

1. Scope and release ID review (3 min)
2. Governance checks status (7 min)
3. Risk and dependency readiness (7 min)
4. Rollback readiness confirmation (5 min)
5. Approval vote and decision logging (8 min)

## Decision criteria

- All mandatory checks are passing
- No unresolved Sev 1/Sev 2 incidents impacting rollout
- Required approvers are present
- Rollback plan can be executed within RTO

## Decision record

- Outcome: Go / No-Go
- Conditions:
- Approvers present:
- Next review time:
