# Release-Ready Operations Packet

This packet provides a ready-to-run operations set for release execution in staging and production.

## Packet contents

- packet-checklist.md: required artifacts and completion checklist
- go-no-go-agenda.md: release gate meeting agenda and decision criteria
- comms-plan.md: communication templates and cadence
- staging-signoff-example-2026-07-09.md: fully filled sign-off example for next staging rollout
- production-signoff-example-2026-07-09.md: fully filled sign-off example for production with stricter thresholds and expanded approvers

## Source governance artifacts

- ../operations-incident-runbook.md
- ../operations-change-approval-matrix.md
- ../operations-release-signoff-template.md
- ../operations-signoff-workflow.md
- ../release-rollout-waves.json

## How to use this packet

1. Copy this folder for each release window.
2. Run governance checks and attach outputs.
3. Execute go/no-go agenda with approvers.
4. Fill sign-off for each rollout wave.
5. Archive completed packet with governance reports.
